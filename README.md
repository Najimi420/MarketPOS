MarketPOS is a Java-based desktop Point of Sale system.

Features:
- Offline POS system
- SQLite database
- Windows installer
- Simple UI for small shops

Installation:
1. Download MarketPOS_Setup.exe
2. Run the installer
3. Launch MarketPOS from Desktop
